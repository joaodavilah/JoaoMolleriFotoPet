# DAVILA — React + Vite

Site institucional em React/Vite com componentes e efeitos integrados do React Bits.

## Rodar localmente

```bash
npm install
npm run dev
```

## Dependências principais

- React
- Vite
- OGL
- Motion
- GSAP 3.13+
- @gsap/react

O `SplitText` usa `gsap/SplitText`, disponível nas versões atuais do GSAP.

## Fontes

Os `@font-face` esperam os arquivos licenciados da Gotham em:

```text
public/assets/fonts/
```
